# Modo História

A aba **Mapa** é a primeira página depois do login. No topo, o cartão do capítulo **Floresta dos Sussurros** mostra o progresso, seguido diretamente pelas seis fases. Selecione a fase disponível para ler o episódio e toque em **Concluir fase** para liberar a próxima. É possível reler as fases concluídas.

O progresso é salvo neste dispositivo, separado por conta, e não sincroniza entre aparelhos. O baú faz parte da narrativa; ainda não concede moedas, XP ou itens.
